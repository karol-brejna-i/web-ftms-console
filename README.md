# FTMS Dashboard (Vite 7)

A React-based console for controlling FTMS (Fitness Machine Service) Bluetooth devices.

## Features
- **Connect/Disconnect**: Pair with Bluetooth FTMS devices.
- **Real-time Dashboard**: View Speed, Heart Rate, Distance, and Time.
- **Controls**: Start/Stop machine, adjust speed (0.1 km/h increments).
- **Logs**: View raw Bluetooth commands and status updates.

## Development
1. `npm install`
2. `npm run dev`
3. `npm run build`

## Deployment
Configured for GitHub Pages. Check `vite.config.ts` base path.
